# Welcome to the AI Engineer Wiki

This is a bilingual (English / Spanish) technical documentation designed for AI engineers and distributed systems practitioners.

## Content Structure

The wiki is organized into **18 modules** divided into two main sections:

### Fundamentals
1. **Networking & Internet** — OSI model, TCP/IP, HTTP/HTTPS, DNS, routing, firewalls
2. **Infrastructure & Containers** — Docker, Kubernetes, CI/CD, Monitoring
3. **Distributed Systems** — Consensus, message queues, distributed caching, event-driven
4. **Operating Systems** — Linux internals, kernel, filesystems, memory, syscalls
5. **Programming & Software Engineering** — Python, design patterns, testing, Git
6. **Databases** — PostgreSQL, MongoDB, Redis, CAP theorem, sharding

### Artificial Intelligence
7. **Machine Learning Fundamentals** — Supervised learning, neural networks, loss functions
8. **Deep Learning** — CNNs, RNNs, Transformers, PyTorch, GPU computing
9. **LLMs — Architecture and Functioning** — Tokenization, decoder-only, attention, KV cache
10. **LLMs — Training** — Pre-training, RLHF, alignment
11. **LLMs — Evaluation and Benchmarking** — MMLU, LM-Eval, hallucination, red teaming
12. **RAG and Vector Databases** — Vector embeddings, vector databases
13. **Fine-Tuning** — LoRA, QLoRA, PEFT, instruction tuning
14. **AI Agents** — Tool use, ReAct, agentic frameworks, multi-agent
15. **AI Security** — Prompt injection, jailbreaking, guardrails, PII
16. **Cloud and AI Infrastructure** — GPU cloud, serverless inference, Terraform
17. **MLOps and Production** — Model serving, monitoring, CI/CD for ML
18. **Multimodal and Computer Vision** — ViT, CLIP, diffusion models
